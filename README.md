# Trand Tracker (viralFinder)

<aside>
🚀

여러 플랫폼의 바이럴 트렌드를 한곳에서 살펴보고, AI 요약과 데이터 기반 인사이트로 다음 행동의 단서를 찾는 트렌드 분석 서비스입니다.

</aside>

## 📌 프로젝트 개요 및 핵심 목표

**Trand Tracker (viralFinder)**는 X(구 트위터), 네이버, 구글·유튜브 등 여러 플랫폼에서 급상승하는 트렌드 데이터를 모아 분석하는 웹 서비스입니다. Spring AI와 Gemini LLM을 활용해 바이럴 키워드의 핵심을 요약하고, 소상공인과 마케터가 참고할 수 있는 인사이트를 제공합니다.

- **멀티플랫폼 통합 수집:** X, Naver, Google/YouTube의 트렌드 데이터를 한곳에서 확인합니다.
- **AI 요약과 인사이트:** Spring AI 기반으로 바이럴 키워드를 3줄로 요약하고 주요 맥락을 제시합니다.
- **근거 기반 의사결정 지원:** 트렌드 관련 수치를 함께 보여 주어 소상공인과 마케터의 트렌드 예측과 기획을 돕습니다.

## 🛠️ 아키텍처 및 시스템 구조

| 영역 | 기술 및 역할 |
| --- | --- |
| Frontend | **React** — 사용자 중심의 실시간 트렌드 대시보드 UI |
| Backend & Crawling | **Python FastAPI** — 크롤링 및 데이터 파이프라인
**Spring Boot** — 데이터베이스 처리 및 API 서버 |
| AI & Database | **Spring AI + Gemini LLM** — 키워드 요약 및 인사이트 생성
**Supabase DB** — 서비스 데이터 저장 |

### 데이터 흐름

1. Python FastAPI 기반 수집 파이프라인이 여러 플랫폼의 트렌드 데이터를 수집합니다.
2. Spring Boot API 서버가 서비스 데이터와 대시보드 요청을 처리합니다.
3. Spring AI와 Gemini LLM이 바이럴 키워드를 요약하고 인사이트 생성에 활용됩니다.
4. React 대시보드에서 트렌드 랭킹과 분석 결과를 확인할 수 있습니다.

## 🔥 핵심 구현 기능

### 실시간 트렌드 탐색

- 급상승 트렌드를 랭킹 형태로 확인할 수 있습니다.
- **통합 / 네이버 / 유튜브 / X** 카테고리 필터로 플랫폼별 트렌드를 탐색합니다.
- 최고 조회수 콘텐츠의 원문으로 이동해 원본 맥락을 확인할 수 있습니다.

### AI 기반 요약과 인사이트

- 바이럴 키워드를 **3줄 요약**으로 빠르게 파악합니다.
- 트렌드 관련 수치와 함께 정보를 제공해 해석과 판단을 돕습니다.

### 사용자 중심 경험과 개인화

- 인터랙티브한 하트(관심) 버튼 애니메이션으로 관심 콘텐츠를 직관적으로 표시합니다.
- **BYOK(Bring Your Own Key)** 방식을 지원합니다. 사용자의 개인 API 키를 브라우저 LocalStorage 기반으로 관리해 공용 서버의 키 사용 및 비용 부담을 줄이는 방향으로 설계했습니다.
- 로그인 회원과 비로그인 게스트/체험판에 차등 이용 정책을 적용합니다.
